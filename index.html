Siap Upload ke GitHub Pages & Install di HP (PWA)

Agar aplikasi bisa diinstal layaknya aplikasi Play Store / App Store di Android & iPhone

Langkah Mudah Hosting Gratis di GitHub Pages:

  1. Simpan kode ini sebagai file bernama index.html.
  2. Klik dua tombol di bawah untuk mengunduh file manifest.json dan sw.js (Service Worker).
  3. Upload ketiga file (index.html, manifest.json, sw.js) ke repositori GitHub Anda, lalu aktifkan fitur GitHub Pages di menu Settings.
  4. Buka link GitHub Pages Anda di Chrome (Android) atau Safari (iOS), lalu pilih "Tambahkan ke Layar Utama / Install Aplikasi".

Konfigurasi Database & Rules Firebase Pribadi

Panduan pengaturan Firebase Console saat aplikasi di-upload ke GitHub Pages pribadi Anda.

3 Langkah Wajib di Firebase Console (console.firebase.google.com):

  1. Buka menu Build → Authentication → Sign-in method, lalu aktifkan provider Anonymous (Wajib agar anggota keluarga bisa langsung masuk tanpa ribet daftar email).
  2. Buka menu Build → Firestore Database, klik Create Database, lalu masuk ke tab Rules.
  3. Salin & tempel kode Firestore Rules di bawah ini ke tab Rules Anda, lalu klik Publish:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Mengizinkan anggota keluarga yang terautentikasi (Anonymous Auth)
    // membaca & menyimpan transaksi, tabungan, dan games pasutri
    match /artifacts/{appId}/public/data/{collectionName}/{docId} {
      allow read, write: if request.auth != null;
    }
  }
}
